# hfashion-project

한섬이 운영하는 패션 이커머스 플랫폼 H Fashion의 기존 UX 구조를 분석하고, 특히 장바구니–주문서–결제 플로우의 이탈률 개선을 목표로 React 기반으로 UI/UX 및 프론트엔드 구조를 리뉴얼한 팀 프로젝트입니다.

## ✨ Key Features

### 1. 사용자 데이터 관리 구조를 설계 및 구현

- 이메일/비밀번호 기반 회원가입과 로그인을 기본으로 구현
- Google 및 Kakao 소셜 로그인을 추가하여 실제 서비스 환경과 유사한 인증 흐름을 구성
- 인증 상태 변화를 전역 상태로 관리하기 위해 Zustand를 활용하여 Auth Store를 구성
- 회원/비회원 로그인 분기, 비회원 주문을 위한 별도 데이터 저장 구조를 설계하여 서비스 흐름에 따라 다른 사용자 케이스를 처리

---

### 2. 헤더 UX 개선 및 로그인 흐름 설계

- 스크롤 시에도 유지되는 고정 헤더 구조 적용
- 로그인 상태에 따라 헤더에 표시되는 아이콘 변경
- 결제 금액을 우측 상단에 고정 모듈 형태로 재배치하여, 사용자가 결제 전체 플로우 동안 항시 가격 정보를 인지할 수 있도록 개선

👉  사용자 행동 흐름에 기반한 직관적이고 연속적인 인터페이스를 제공

---

### 3. 카테고리 구조의 복잡성 개선

-  카테고리 메뉴를 축소 및 재배치하여 브랜드 분위기를 살리고 뎁스를 얕게 구성

👉 사용자가 더 직관적으로 탐색 가능한 환경을 제공

---

### 4. 메인 페이지 UX/UI 설계

- 1. 풀스크린 스와이퍼 대신 뷰포트 높이 조정 -> 여유로운 느낌을 줌과 동시에 다음 섹션 타이틀 일부 노출로 스크롤 유도
- 카드형 레이아웃 중심 구성으로 빠른 정보 스캔 가능
- 카드 반복으로 인한 피로도를 줄이기 위해 중간에 대형 비주얼 섹션 배치

👉 사용자의 쇼핑 흐름을 고려한 섹션 재배치로 쇼핑중 이탈률 감소

---

## 📈 What I Learned

- 쇼핑몰 서비스에서 결제 직전 UX가 전환율에 미치는 영향을 구조적으로 이해
- React 컴포넌트 단위 설계를 통한 UI 재사용성과 유지보수성 경험
- UX 기획 → UI 설계 → 프론트엔드 구현까지 전체 흐름을 연결하는 경험
- 회원·비회원 로그인 분기, 소셜 로그인, 주소 검색 기능을 포함한 회원가입/로그인 플로우를 구현하여 실제 이커머스 서비스 수준의 인증 UX 설계 역량 강화
